# Anthony Baker Portfolio — Design Directions

## Three possible directions

### Circuit Fieldbook
**Very Brief Intro:** A tactile technical journal that turns Anthony’s systems work into annotated field notes, using deep teal, blueprint structure, and vivid safety-green accents from the existing site. It feels methodical, hands-on, and quietly nerdy rather than sci-fi.
**Probability:** 0.07

### Lab Bench Editorial
**Very Brief Intro:** A warm off-white editorial portfolio with monospaced technical marginalia, archival photography, and occasional equipment-label details. It presents projects as carefully documented experiments.
**Probability:** 0.04

### Terminal Observatory
**Very Brief Intro:** A dark, data-rich interface with constellation-like network maps and a sparse terminal vocabulary. It is immersive and cinematic, with an emphasis on security and infrastructure.
**Probability:** 0.09

## Chosen approach — Circuit Fieldbook

### Design Movement
**Digital brutalism tempered by technical field notes.** The direction reinterprets the existing site’s deep teal, near-black atmosphere and lime-green navigation markers as a practical systems notebook, not a generic cyberpunk dashboard.

### Core Principles
1. **Show the work, not decorative technology.** Every visual detail should feel like it helps label, index, measure, or reveal Anthony’s projects.
2. **Asymmetry with hierarchy.** Major content sits in a left-aligned document column while compact data modules, index labels, and status indicators occupy the opposing edge.
3. **Tactile precision.** Fine rules, dotted grids, framed cards, and tabular metadata create a convincing fieldbook material language.
4. **Human engineering.** Clear prose and breathable spacing offset the technical density, showing a practitioner who can communicate as well as build.

### Color Philosophy
The foundation is **deep blue-green ink** inspired directly by bakerinfo.org, which gives the site a distinct systems-and-infrastructure identity. It is paired with a restrained **radioactive chartreuse** for active states, focus rings, data marks, and small details—an ownable signal color rather than an all-over glow. Pale mineral paper and muted steel-grey create calm, high-contrast reading surfaces.

### Layout Paradigm
The page is an **indexed fieldbook** rather than a central landing page. A narrow vertical index anchors desktop navigation; the hero opens like a cover sheet; sections alternate between broad narrative panels and technical sidecar modules. Project cards stack into varied spans so the page reads like a working archive, not a uniform marketing grid.

### Signature Elements
1. A small **green coordinate grid / node mark** appears in the brand, section labels, and project metadata.
2. **Field tags** with page references, stack labels, and repository status markers organize content.
3. **Blueprint rules and dotted guide lines** connect project details and skill measurements across the composition.

### Interaction Philosophy
Interactions should feel like operating a well-made tool: direct, legible, and responsive. Navigation reveals section position, cards lift only slightly, and contact controls communicate state immediately. External links use an arrow-out cue rather than ambiguous text.

### Animation
At initial load, the hero’s identifiers and data blocks reveal in a short stagger (40–70ms) using opacity and a 6px vertical translation. Dotted map lines use a subtle single sweep, then stop. Card hover uses a 160ms transform and border-color transition; buttons compress to 0.97 on press. All non-essential animation is disabled when reduced motion is preferred.

### Typography System
**Space Grotesk** carries display headings and large project titles with a confident, engineered rhythm. **IBM Plex Mono** handles labels, code-like microcopy, skill indicators, and metadata. Headings have tracked uppercase labels above them; body copy uses a readable, humanist sans fallback and never competes with the technical annotations.

### Brand Essence
**Anthony Baker builds practical, security-minded systems and useful tools for people who prefer technology understood from the inside out.** Personality: observant, hands-on, candid.

### Brand Voice
Headlines should be concise, active, and specific; CTAs should describe the destination; microcopy should sound like a reliable collaborator’s technical note. Avoid generic corporate promises or inflated claims.

> “Build it. Inspect it. Make it useful.”

> “Open the repo, trace the decisions.”

### Wordmark & Logo
The logo is a hand-drawn **AB** monogram constructed as a compact circuit-node path inside an open square coordinate grid. The wordmark uses a customized monospaced treatment with a small `/sys` label, never a default typeset name.

### Signature Brand Color
**Signal Lime — #A6FF4D.** It is used only for active signals, key calls to action, and metadata emphasis against deep teal.
